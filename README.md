# Habify
A personal, responsive habit and wellness tracker.

## Publish on GitHub Pages
1. Upload `index.html` to the root of your public `habify` repository.
2. In repository **Settings → Pages**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Visit `https://YOUR-USERNAME.github.io/habify/` after GitHub finishes publishing.

## Privacy and storage
Your entries are saved in your browser's local storage, not to GitHub. The app does not sync data across devices. Use Settings → Export backup to keep a copy.
